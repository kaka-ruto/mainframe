# web-fetch

MCP server + CLI that reads any web page as clean Markdown for AI agents.

## Dependencies

- Python 3.10+
- patchright Chromium (installed by install.sh)

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/anywaye/web-fetch/master/install.sh | sh
```

## Secrets

None.

## Test

```bash
mf mcp test web-fetch
```
