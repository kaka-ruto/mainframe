# Browse MCP

Browser automation MCP server. Drives the user's real Chrome browser via a relay extension.

## Prerequisites
- Chrome browser with browse extension installed
- `~/.local/bin/browse` binary

## Tools
- `execute` - Run JavaScript to drive the browser
- `status` - Report relay and browser status
- `tabs` - List, open, or close tabs

## Test
```bash
mf mcp test browse
```
